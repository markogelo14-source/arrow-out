## How it plays
A grid is filled with arrows. Tap an arrow and it slides off the board in the direction it points, as long as nothing is in the way. If another arrow blocks it, it bumps into it, bounces back, and you lose a heart. Clear every arrow to win. You have 3 hearts per level.

- Arrows are 1 to 3 cells long, so long arrows can block several lanes at once.
- Every level is generated by code and is always solvable (it is built by placing arrows in reverse removal order).
- Levels get bigger and denser as you go: the board grows once per chapter of 8 levels, from 4x4 in chapter 1 to 8x10 from chapter 11 (level 81). 3-cell arrows arrive in chapter 3. Levels are endless.
- **Daily Puzzle:** one bigger board per day, the same for every player.
- **Hints:** 3 per level; a hint highlights an arrow that can escape right now.
- **Level map:** levels are grouped in chapters of 8 on a map; cleared levels can be replayed.
- **Daily streak:** the home screen shows the last 7 Daily Puzzles, and solving one shows the streak with a Share button.
- **Win card:** hearts left, hints used and time, with arrow confetti. A progress bar in the game header fills as arrows leave.
- Haptic feedback on every move.

## Short pitch
Arrowly is a calm, one-thumb logic puzzle. Look at the board, find the arrow with a clear path, and tap it away. One wrong tap costs a heart, so think before you tap. Endless generated levels and a fresh Daily Puzzle every day.
