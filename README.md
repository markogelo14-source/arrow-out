# Arrowly

A simple arrow escape puzzle game for iPhone: tap an arrow and it slides off the board, unless something is in the way.

- `game/`: the iOS app (SwiftUI)
- `website/`: the static website (landing page, privacy policy, support, blog)
- `appstore/`: App Store submission kit (listing copy, checklist)
- `research/`: game idea research

Website: https://markogelo14-source.github.io/arrow-out/ (deployed from `website/` by GitHub Actions)
